# 山隅咖啡

React + TypeScript + Vite 咖啡店演示项目。包含首页、六款咖啡与三款甜品、本地购物袋、杯型与优惠试算，以及菜单、订单、个人中心展示页，支持手机和桌面浏览器。

优惠规则集中在 src/pricing.ts，改动杯型、数量或商品后自动重算：咖啡第二杯半价（甜品不参与，按单价两两配对，每对中较便宜的一杯半价），半价后满 ¥50.00 减 ¥8.00，会员 95 折与满减不叠加、自动取更省的一项。

所有商品、会员和订单内容均为本地示例数据，图片为原创概念素材。购物袋与会员状态保存在当前浏览器，不涉及后台接口、支付或真实下单。

## 本地运行

使用 package.json 中 engines 支持的 Node.js 版本，.nvmrc 提供版本参考。

```sh
npm ci
npm run dev
```

开发服务仅监听本机，默认地址为 http://127.0.0.1:5173，以终端实际输出为准。

## 构建与本地预览

```sh
npm run build
npm run serve:dist
```

构建产物位于 dist，本地静态预览默认地址为 http://127.0.0.1:4173。

npm run typecheck 可单独检查 TypeScript 类型。安装依赖前，编辑器可能提示缺少 React、Node 或 Vite 类型，安装完成后即可检查。
