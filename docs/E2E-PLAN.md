# E2E 完整流程与证据

测试环境：独立浏览器上下文，本地数据，Chromium 390×844、WebKit 390×844、桌面1280×900；布局另外覆盖320/375/430。测试运行前检查站点就绪；结束输出 HTML、JSON 和原始日志。

主流程：空购物袋→美式19+拿铁22→未领券41→打开活动规则→领取→购物袋31→取消使用41→重新启用31→减去拿铁19且显示差额→恢复拿铁31→刷新仍31→清空为0→刷新仍空且券保留。录制真实视频，截图领取前后和购物袋金额。

补充：重复领取/快速连续点击不重复；无券不可优惠；每单最多10元；边界3899/3900/3901/7800用规则测试；存储写入失败显示错误且可重试；畸形状态恢复；数量非负/非法商品不被接受；商品删除和数量修改回归；菜单/订单/我的导航与直接刷新；图片加载；无页面错误、无第三方请求；触控尺寸/底栏避让/横向溢出；键盘关闭、焦点约束与恢复。

生产阶段同一套 E2E 在 dist 本地静态服务器上执行，不能只跑首页 HTTP 检查。记录浏览器安装情况，手机视口模拟不称作实体手机测试。

失败证据保存 trace、截图和视频。只在真实失败时修复，不制造失败日志；测试主动注入错误属于异常路径验证，不能宣称为自然故障。
