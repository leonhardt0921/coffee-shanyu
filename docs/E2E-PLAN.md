## 隔离与运行
独立用例用新浏览器上下文。手机Chromium390×844、手机WebKit390×844、桌面Chromium1280×900；布局加320/375/430及长列表320×568。模拟视口不等于实体手机。
npm run setup:browsers安装项目独立浏览器。npm run test:e2e与npm run test:e2e:prod自动管理本地服务，不复用未知进程。每轮设置新的E2E_REPORT_DIR=artifacts/<run-id>/<attempt>/development或production，避免覆盖。

## 连续主流程 A01–A04
真实UI完成，不能向localStorage塞入主流程结果；用例名标验收ID：
1. 新上下文打开首页核对6商品，领取启用旧券。

## 补充旅程
- 同杯型重复加购合并；不同商品不串行；多杯整行改配保留数量；取消/关闭/Escape不落库；99上限与60+50合并拒绝。
- 旧券完整回归：标准美式19+拿铁22，未领41→领取31→取消41→启用31→减拿铁19→加拿铁31→刷新31→清空0，券保留。
- 旧数据初始化仅一次：shanyu-cart-v1={"americano":1,"latte":1}，shanyu-coupon-v1={"activityId":"opening-10","claimed":true,"enabled":true}。期望标准两行41/31；多次刷新不重复迁移；改配刷新保留新杯型；清空刷新不复活。另测已领未启用券。
- 测试注入Storage.setItem失败，添加/改配/迁移不假保存、不丢数据，解除后可重试；标“主动异常路径验证”。注入不得进入生产代码。
- 非法JSON、未知商品/杯型、非法数量及混合有效无效数据：有效行保留，非法行不污染金额。
- 首页/新弹窗移动适配、触控尺寸、底栏避让、长购物袋滚动、焦点/Escape/恢复、reduced-motion；导航/直接刷新/本地图片。
- 捕获pageerror、非本地HTTP(S)、HTTP错误及真实资源失败，不能屏蔽所有网络错误让测试绿。
