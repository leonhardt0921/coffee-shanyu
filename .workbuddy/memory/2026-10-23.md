# 2026-10-23

## 优惠体系重构（第二杯半价 + 满减 + 会员折扣）

- 新增 `src/pricing.ts`：纯函数引擎 `quote(entries, isMember)`，所有优惠从购物袋现算，改杯型/数量/商品自动重算。
  - 第二杯半价：只把 coffee 按杯展开单价 → 降序排序 → 索引 1,3,5… 半价（甜品排除）。排序后配对是「最省」组合，3 杯只减 1 杯、4 杯减 2 杯。
  - 满减：按**半价后**金额判定，≥ ¥50 减 ¥8，每单一次。
  - 会员 95 折同以半价后金额为基数；与满减互斥，取金额更大者（相等时选满减）。
- 商品模型：新增 `category: coffee | dessert`、3 款甜品（巴斯克/布朗尼/燕麦曲奇）；杯型 `medium | large`，大杯 +¥3，仅咖啡生效；购物袋行键改为 `id|size`（localStorage key 升到 `shanyu-cart-v2`，读旧 v1 键自动迁移）。
- 删除 `coupon.ts` / `useCoupon.ts` / `CouponComponents.tsx`（原满39减10开业券），改为 `PromoComponents.tsx`（活动卡 + 规则弹窗 + 购物袋优惠明细 + 会员开关）；新增 `useMember.ts`（默认开启，key `shanyu-member-v1`）。
- 用户确认的决策：满50减8 为唯一满减；杯型两档（中杯原价/大杯+3）；新增 3 款甜品。

## 环境备注

- 该项目 Vite 8 用 rolldown，**没有 esbuild**，无法用 `esbuild --bundle` 跑 TS 校验脚本。
- 项目 package.json 是 `"type": "module"`，tsc 输出 commonjs 到项目内目录会被当 ESM 解析而报 `exports is not defined`；临时校验脚本用完即弃，未入库。
